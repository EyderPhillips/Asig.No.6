Conceptos básicos del desarrollo web

¿Qué es una página web?

Una página web es un documento digital escrito principalmente en HTML que se puede ver desde un navegador como Chrome, Firefox o Edge. Puede contener texto, imágenes, videos, audio, enlaces y formularios.

Un conjunto de páginas web relacionadas entre sí y alojadas bajo una misma dirección forma un sitio web.

Cada página web tiene una dirección única llamada URL (por ejemplo, https://www.utp.ac.pa), que funciona como la dirección de una casa: le indica al navegador exactamente dónde encontrar el documento que quiere mostrar. Esa dirección está formada por un protocolo (http o https), un nombre de dominio y, en ocasiones, la ruta de un archivo específico dentro del sitio.

El lenguaje base de toda página web es HTML (HyperText Markup Language, o Lenguaje de Marcas de Hipertexto). No es un lenguaje de programación, sino un lenguaje de marcado: usa etiquetas para indicarle al navegador qué es cada parte del contenido, por ejemplo un título, un párrafo, una imagen o un enlace. Normalmente se complementa con CSS, que se encarga del diseño y los colores, y con JavaScript, que agrega interactividad.

Lo que hace especial a la web es el hipertexto: los enlaces permiten saltar de una página a otra, o de una sección a otra, con un solo clic. Gracias a esto, millones de documentos en todo el mundo quedan conectados entre sí.

¿Cómo funcionan las páginas web?

Las páginas web funcionan mediante un modelo cliente-servidor. El cliente es el navegador del usuario y el servidor es la computadora donde está guardado el sitio.

El cliente es quien pide información: puede ser una computadora, un celular o una tableta con un navegador instalado. El servidor es una computadora conectada a internet las 24 horas, cuyo trabajo es almacenar los archivos del sitio y entregarlos cada vez que un cliente los solicita. La comunicación entre ambos se realiza mediante un protocolo llamado HTTP (o HTTPS cuando la conexión va cifrada y es más segura).



Proceso básico

  1. El usuario escribe una dirección (URL) en el navegador. También puede llegar a ella haciendo clic en un enlace o usando un buscador como Google.
  2. El navegador envía una solicitud al servidor. Antes, un sistema llamado DNS traduce el nombre del sitio (como utp.ac.pa) a la dirección numérica (dirección IP) del servidor que lo aloja.
  3. El servidor responde enviando los archivos de la página. Estos pueden ser el documento HTML, las imágenes, los videos, los audios y otros recursos que el sitio necesite.
  4. El navegador interpreta el código y muestra la página. Lee el HTML de arriba hacia abajo, solicita los recursos que faltan y arma la página visual que ve el usuario.

Tipos de páginas web

Según la forma en que se genera y se entrega su contenido, las páginas web se clasifican principalmente en dos grandes tipos: estáticas y dinámicas. Conocer la diferencia ayuda a decidir qué tecnología usar al crear un sitio nuevo.

Páginas estáticas

Muestran siempre el mismo contenido a todos los usuarios. Están hechas con HTML (y normalmente CSS) y solo cambian si el desarrollador modifica los archivos. Son rápidas y sencillas de publicar.

Como el servidor solo entrega archivos ya terminados, no necesitan base de datos ni programación del lado del servidor. Esto las hace más económicas de alojar, más seguras (hay menos puntos por donde atacarlas) y muy veloces al cargar. Su desventaja es que actualizarlas implica editar el código directamente, y no permiten mostrar información personalizada para cada visitante. Son ideales para portafolios, páginas de presentación, folletos digitales o sitios informativos que casi no cambian, como la página que estás construyendo en esta asignación.

Páginas dinámicas

Cambian su contenido según el usuario, la hora o los datos guardados en una base de datos. Requieren programación del lado del servidor o del cliente. Un ejemplo son las redes sociales, donde cada persona ve contenido distinto.

En estas páginas, el servidor no entrega un archivo fijo, sino que genera la página en el momento en que el usuario la solicita. Para lograrlo consulta una base de datos, procesa la información con lenguajes como PHP, Python, Java o JavaScript (Node.js) y arma el HTML final. Por eso pueden mostrar el saldo de una cuenta, los productos de un carrito de compras o las publicaciones de tus amigos. Su desarrollo es más complejo y su mantenimiento más costoso que el de una página estática, pero ofrecen mucha más flexibilidad e interacción.

Diferencia entre una aplicación web y un sitio web

Aunque ambos se visitan desde el navegador y muchas veces se confunden, tienen propósitos distintos. La diferencia principal está en qué tanto participa el usuario: en un sitio web normalmente consulta información, mientras que en una aplicación web realiza acciones y trabaja con sus propios datos.

Sitio web

Su objetivo principal es informar. El usuario consulta contenido pero casi no interactúa con él. Ejemplos: la página de una universidad, un blog o un portafolio.

Su contenido suele ser el mismo para todos los visitantes y se organiza en páginas con textos, imágenes y enlaces. No requiere que el usuario inicie sesión para ver la información, y normalmente su desarrollo es más sencillo y rápido. Los sitios web también pueden ser dinámicos, por ejemplo un blog administrado con un gestor de contenidos, pero su función principal sigue siendo mostrar información.

Aplicación web

Su objetivo es que el usuario realice tareas e interactúe con el sistema, por ejemplo iniciar sesión, enviar datos o procesar información. Ejemplos: un correo electrónico en línea, un banco en línea o un editor de documentos.

Funciona de forma parecida a un programa instalado en la computadora, pero se usa directamente desde el navegador, sin instalar nada. Casi siempre requiere una cuenta de usuario, guarda información en una base de datos y responde a las acciones de la persona en tiempo real. Por ejemplo, en un correo en línea cada usuario ve sus propios mensajes y puede escribir, enviar y organizar correos. Su desarrollo suele ser más complejo, porque exige manejar usuarios, seguridad y datos.
