Lenguajes del desarrollo web

Una página web se construye combinando tres tecnologías. Una forma sencilla de entenderlas es compararlas con una casa: HTML son las paredes y la estructura, CSS es la pintura y la decoración, y JavaScript es la electricidad que hace que las cosas funcionen.

HTML: la estructura

HTML (HyperText Markup Language) es el lenguaje que define el contenido de la página: títulos, párrafos, imágenes, enlaces, tablas y formularios. No es un lenguaje de programación, sino de marcado, porque utiliza etiquetas para indicarle al navegador qué es cada elemento.

Cada etiqueta se escribe entre signos de menor y mayor que, y normalmente tiene una apertura y un cierre. Por ejemplo: 

<h1>Hola, mundo</h1> <p>Este es mi primer párrafo.</p>

CSS: el diseño

CSS (Cascading Style Sheets, u Hojas de Estilo en Cascada) es el lenguaje que controla la apariencia de la página: colores, tipos de letra, tamaños, márgenes y la forma en que se distribuyen los elementos en la pantalla.

Gracias a CSS se puede cambiar todo el diseño de un sitio sin modificar su contenido. Un ejemplo de cómo luce una regla de CSS: 

h1 {
        color: blue;
        font-size: 32px;
        }

Esta regla le indica al navegador que todos los títulos principales se muestren en color azul y con tamaño de 32 píxeles.

JavaScript: la interactividad

JavaScript es un lenguaje de programación que permite que la página responda a las acciones del usuario. Con él se pueden crear menús desplegables, validar formularios, mostrar mensajes, hacer animaciones y actualizar información sin recargar la página.

Un ejemplo sencillo: 

alert("¡Bienvenido al curso!");

Esta instrucción haría aparecer una ventana emergente con el mensaje de bienvenida. En esta asignación no se utiliza JavaScript, ya que el trabajo se realiza únicamente con HTML, pero es el siguiente paso natural en el aprendizaje del desarrollo web.

Resumen

  • HTML: define qué contenido tiene la página.
  • CSS: define cómo se ve ese contenido.
  • JavaScript: define cómo se comporta e interactúa.

Áreas del desarrollo web: frontend y backend

El desarrollo web se divide en dos grandes áreas que trabajan juntas. Una se encarga de lo que el usuario ve y toca, y la otra de lo que ocurre por detrás, en el servidor.

Frontend: lo que el usuario ve

El frontend es la parte de la página con la que el usuario interactúa directamente en su navegador: los botones, los menús, los textos, las imágenes y los formularios. Los desarrolladores frontend se encargan de que el sitio se vea bien, sea fácil de usar y funcione correctamente en computadoras, tabletas y celulares.

Tecnologías del frontend

Las tecnologías base son HTML, CSS y JavaScript. Además, se suelen usar herramientas adicionales llamadas frameworks, como React, Angular o Vue, que ayudan a construir interfaces más complejas de forma ordenada.

Backend: lo que ocurre detrás

El backend es la parte que el usuario no ve. Funciona en el servidor y se encarga de procesar la información, guardar y consultar datos en una base de datos, validar usuarios y aplicar las reglas del sistema.

Por ejemplo, cuando inicias sesión en una página, el frontend muestra el formulario, pero es el backend el que comprueba si tu usuario y contraseña son correctos.

Tecnologías del backend

Se usan lenguajes como PHP, Python, Java, C# o JavaScript (con Node.js), junto con bases de datos como MySQL, PostgreSQL o MongoDB, donde se almacena la información.

Desarrollador full stack

Se le llama desarrollador full stack a la persona que domina tanto el frontend como el backend y puede construir una aplicación completa de principio a fin. Para llegar ahí, lo más recomendable es empezar por lo básico: primero HTML, después CSS y JavaScript, y más adelante el área del servidor.
